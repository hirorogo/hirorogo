## 自己紹介 & 関心分野

- **セキュリティ研究 & 脆弱性調査**: セキュリティ学会・カンファレンス発表を目指したセキュリティリサーチ、脆弱性検証、セキュリティレポート作成。
- **OSS コントリビューション**: 各種オープンソースプロジェクトへの機能追加、バグ修正、仕様改善。
- **エージェント & Bot 開発**: AI Agent（Claude Code 等）と連携する Discord Bot、自動化ツール、Web サービスの構築。
- **インフラ & ネットワーク**: Kubernetes (k8s) クラウドデプロイ、Deno Deploy、ネットワークツール作成。
